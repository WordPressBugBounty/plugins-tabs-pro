== Description ==
Tab Shortcode Ultimate is yet another simple, responsive, lightweight tabs plugin for creating responsive tabbed panels with unlimited options and transition animations support.

This plugin allows you to use shortcode to display tabs post/page or widget via unique post ID. You can easily Manage tabs via options page.

### 🚀 Key Features & Options

* **Multiple Tab Layouts:** Easily switch between **Horizontal** and **Vertical** tab layouts.
* **Flexible Tabs Alignment:** Align your navigation tabs to the **Left**, **Center**, **Right**, or **Justified**.
* **Menu Styles & Positions:** Choose custom menu styles and control menu positions (top/bottom).
* **Auto Open Tab Index:** Set a specific default active tab to load automatically.
* **Activator Events:** Switch user interaction between **Click** and **Hover**.
* **Auto Height Mode:** Dynamic content height control for seamless layouts.
* **Smooth Transitions & Animations:** Configure entrance effects with customizable animation speeds.
* **URL Hash Links:** Direct linking support to open specific tabs via URL parameters.
* **Live Preview:** Real-time preview support right inside your WordPress dashboard.
* **Clean OOP Code & High Performance:** Built on modern Object-Oriented Programming principles with CSS Custom Properties (CSS Variables) for optimal speed.
* **Fully Responsive:** Looks stunning on all mobile devices, tablets, and desktops.
* **Advanced Transition Effects** (fade, slideUp, slideRight, flip, rotate, scaleDown, etc.)
* **Drag & Drop Tab item sorting from the backend**
* **Comprehensive color customization** (titles, active states, hover texts, borders, and content backgrounds)
* **24/7 Dedicated Support Forum**

== Installation ==

1. Install as regular WordPress plugin.
2. Go your Pluings setting via WordPress Dashboard and activate it.
3. After activate plugin you will see a button on the post or page visual editor called tptabs_ultimate Shortcode. Click on it, from there you will receive the shortcode.<br />

* Corrected variable parameter ordering within the dynamic style builder for accurate border and hover text rendering.
